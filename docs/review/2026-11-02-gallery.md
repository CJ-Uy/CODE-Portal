# Gallery album sharing and personal photo library

Added a Share album action using the browser share sheet, with clipboard fallback.
Album links omit photo and layout query parameters and retain existing member access.
Photo links copied from personal collections point at the original album, so another
member can open them without needing access to the sender's private collection.

The bookmark immediately follows the heart in the photo toolbar. Saving defaults to
Saved. Saved photos can belong to multiple private lists. Members can create lists
from their library or while saving a photo, change list membership, and delete lists.
Deleting a list preserves its saved photos. Removing a bookmark removes the photo
from that member's lists and leaves the heart unchanged. Liked by you lists the
current member's hearts. The default personal library is `/portal/gallery/saved`.

## Multi-select follow-up

Select photos is now a labeled button on mobile and desktop. Selection switches
the roll to its existing grid, with per-photo checkmarks, a selected count,
Select all, and Clear. The toolbar supports Download, Save, Add to list, Move,
and Delete. Download exports exactly the selected originals in one ZIP; selection
stays available afterward for adding those same photos to a list. Members can
choose an existing private list or create one for the selection.

Batch saves validate ownership and every photo before writing, deduplicate IDs,
and split inserts below D1's parameter limit. Failed requests keep the selection.
The list picker shows errors inside the sheet. Closing a sheet with Escape does
not exit selection mode.

Downloads use the ZIP writer already bundled in the installed `xlsx` dependency,
loaded only when needed. No dependency or additional schema change was added.
Archive filenames are numbered and made ASCII-safe. ZIPs are assembled in browser
memory, so large selections containing videos can use substantial memory.

Browser follow-up passed against the built app: select/deselect, Select all/Clear,
empty-selection download disabled, a real ZIP download, Save, adding selected
photos to a new list, persistence after reload, and Escape preserving selection.
The unselected photo stayed out of the chosen list. Layout checks passed at 320px
and 1280px. Python's independent ZIP reader verified both original PNG entries,
distinct filenames, and valid CRCs in the browser-downloaded archive.
