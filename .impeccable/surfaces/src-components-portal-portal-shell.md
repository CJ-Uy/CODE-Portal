# Member portal navigation

Mode: Operate. Extend the existing CODE palette, Unna headings and Source Sans controls.

Members move between Home, Calendar, Retention and Profile using four bottom tabs around the existing plus button. Event check-in is the most frequent reason members open the site, so its QR card stays expanded at the top of the menu. Create event and New short link follow it, then the released destinations absent from those tabs.

The sheet's handle and title stay fixed while its contents scroll. Dragging the handle moves the sheet with the pointer. A downward release of at least 80 pixels dismisses it; shorter or cancelled gestures return it to its starting position. The close button, handle activation, Escape and backdrop remain available. Reduced motion removes the snap-back transition and sheet animation.

Mobbin deep research informed the grouping and handle placement: [ChatGPT action sheet](https://mobbin.com/screens/cf94f6ed-ad32-48c1-ad40-e8ee75e9615a), [Google Photos divided menu](https://mobbin.com/screens/d8328f55-9c5e-4534-97e7-90aecb98965e), and [Alta center action tab bar](https://mobbin.com/screens/ea15a792-a95f-42ae-b9c0-fa1087daf1d8).

The desktop rail leads with Home, Calendar and Retention. Group the remaining destinations by task: Community contains Announcements, Ments Tree and Gallery; Resources & tools contains Library, Important links, Link shortener and Guides; Personal contains Mail, Notifications and Profile. Use the same groups in the mobile sheet, omitting pages already in its bottom tabs. Keep headings visible, with no extra disclosure steps. Pinned links follow these groups. Hide unavailable destinations and empty groups through release flags.

Link shortener fills the Retention tab when Retention is unavailable. Creation links open the existing forms through create=1, including repeat visits on the same page; closing removes that parameter and preserves other query parameters.
