# Important links

Mode: Operate. Scope: the member directory at /portal/important-links and its admin editor at /portal/admin/content/important-links. Members find an official CODE file fast; admins keep the list current. Pinned sidebar links are the same records with Show in sidebar on.

## Direction contract

THESIS: One trusted shelf for CODE's official files. A member scans by category and opens the right sheet, doc or form in one tap. Refuses the link-in-bio stack of identical pill buttons and the grid of same-size icon cards.

OWN-WORLD: The existing CODE workspace. White card lists with divided rows on the page ground, Unna category headings in navy, Source Sans rows, light blue type tiles with accent icons, light blue hover tint. No new tokens.

STORY: A member arrives looking for the masterfile or a form. Category headings in admin order lead into rows. Each row names the file, says what it is for, shows its type and the site it opens, and opens in a new tab. Admins see Edit links; with nothing published, admins get a direct path to add the first link and members learn who fills the page.

FIRST VIEWPORT: Unna h1 Important links with a one-line purpose, Edit links at the right for admins. Category sections follow, two columns of section stacks on wide screens, one column on phones. Each row: 40px light blue type tile, semibold title, muted description, a meta line such as Spreadsheet · docs.google.com, trailing external-link mark.

FORM: Local extension of the admin tool directory's grouped divided rows, item 1 of 1 because the request specified the structure. Not rolled; no seed key.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## Research

- [Aboard documents](https://mobbin.com/screens/e197b54c-160f-469c-8bdf-642982d409ae): category headers with a count and per-category actions above row lists, Add category at the end. Shapes the editor.
- [Raycast about](https://mobbin.com/screens/d14694ba-816e-4103-ae9e-f1a7e73cecb8): grouped inset lists with a leading glyph and a quiet section label. Shapes the phone layout.
- [YouTube channel links](https://mobbin.com/screens/b89f66e5-136d-4dec-950e-6d23f893dfce): the destination domain under each title, so members know where a link goes before tapping.
- [Oyster tools and resources](https://mobbin.com/screens/26904b37-da5c-4004-b3ff-9c0e9278b1e5): file type mark beside title and description.

Quality bar: no horizontal page overflow at 390 px with long titles, descriptions and URLs; rows keyboard focusable with visible focus; every external link announces that it opens a new tab.
