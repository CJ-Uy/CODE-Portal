# Ments Tree

Mode: Operate. Preserve CODE typography, colors and member permissions. The user pinned the structure: show the complete connected forest, make it fun to explore, add useful tree statistics, let admins edit official relationships and let members report their own informal Pments directly.

Direction: one large canvas with every generation visible, solid official connections and optional dashed Pment connections. Search, fit, zoom, fullscreen and direct person links keep the forest navigable. People remain keyboard-accessible HTML controls. The complete forest precedes statistics and the member's Pment editor. Admin changes stay in the existing member management section.

Follow-up requirements: trees grow down from mentors to mentees. Drag or swipe pans the canvas; the mouse wheel zooms around the pointer. The signed-in member opens centered at 50% when a linked account or unique matching name identifies them. Find me returns to that view. Use larger 260 by 144 person controls with complete wrapped names. Ments sits above Profile in the main navigation alongside Links, Mail and Notifications. The lower group is labeled Resources & updates; feature flags determine availability independently.

Research inspected: [Workable](https://mobbin.com/screens/46d531ba-fda0-4138-a43b-821e1b5c20fb), [Deel](https://mobbin.com/screens/c4ca67a1-4971-4188-8c6b-52bf79cc5e12), [Aboard](https://mobbin.com/screens/d63f0f3e-ed6e-4229-adbf-2e9b980f0d88), [Qatalog](https://mobbin.com/screens/6a5b572a-0888-48fd-89ed-6910ea6c5eeb). Connected person nodes, canvas controls and a stable search are the relevant patterns. No replacement brand or raster comp.

Finish requires desktop and mobile exploration, current screenshots, a fresh reviewer verdict and scoped design documentation. Beta database changes require the repository's migration approval.
